# 飞牛应用中心 · 应用介绍（精简版）

> 写入 `fpk/manifest` 的 desc。**不含图片**（应用中心会裁切；fnpack 对 desc 也有约 412 字限制）。
> 已去掉重置密码（登录页有说明）。

## 包内文案

多平台搜歌、本地音乐库、标签整理与高品质下载。兼容落雪、澜音、MusicFree、BakaMusic 音源插件，浏览器内完成找歌 → 试听 → 下载 → 整理。

**亮点**
- 搜索：酷我 / 酷狗 / QQ / 网易云 / 咪咕等（依导入脚本）；FLAC · Hi-Res · 母带，支持批量下载
- 音乐库：每日推荐（本地+平台混搭）、推荐歌单、漫游播放
- 文件管理：标签编辑、清理（重复/小文件）、伪 FLAC 检测、按歌手整理
- 播放：全屏逐字歌词、频谱与风格配色

**依赖**：应用中心 Node.js v22。目录可在安装向导或「访问权限」中指定；卸载可选保留配置。
