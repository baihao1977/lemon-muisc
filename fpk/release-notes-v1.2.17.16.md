# 柠檬音乐 v1.2.17.16

## 更新内容

### 飞牛 / FPK（修 1.2.17.15 升级后无法启用）

- 修复升级到 1.2.17.15 后无法启用（`ERR_MODULE_NOT_FOUND`）：新增 MusicFree 依赖 `axios` / `cheerio` 后未触发 npm 补装；启用时检测并补齐
- 修复补装后仍提示缺少 axios/cheerio：npm 装到实体 `node_modules` 后被错误丢弃、链回旧持久目录；改为用新安装结果覆盖持久依赖

### 下载

- 大文件 / 母带下载：取消「整段 2 分钟」读超时误杀；改为无数据空闲超时，并支持 `.part` 断点续传
- 服务重启后卡住的「下载中」任务会自动重新入队并尽量续传
- 假无损校验失败等场景提示更准确，不再一律显示「网络抖动」

### 音质升级

- 匹配顺序：先当前激活音源，再试其它已激活音源（有的源无母带、有的有）
- 未匹配到目标音质时，升级页顶部明确提示，避免误以为卡住

### 其它

- 普通用户「允许下载」开关
- 听歌排行本地曲误标「网络」修复；列表无元数据时不再整列显示「—」
- 用户列表表头与操作列对齐
- 检测到新版本 / 用户数据变更时自动备份
- 移动端音频焦点混音相关修复

## 安装 / 更新

- x86：`lemon-music-1.2.17.16-x86.fpk`
- ARM：`lemon-music-1.2.17.16-arm.fpk`
