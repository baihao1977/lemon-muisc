# 柠檬音乐 v1.2.17.17

## 更新内容

### 音源

- **MusicFree / BakaMusic**：万象等分片插件在设置里合并为「合集」，可按平台单独开关
- **合集导出**：合集音源可一键导出全部平台脚本到「音源导出」目录，本地多选导入即可恢复
- **汽水等无检索能力的平台**：未提供搜索/下载时不在搜索栏显示
- **MusicFree 播放**：取链失败显示真实原因；不再误跨到内置平台乱搜成歌

### 听书

- 番茄 / 七猫 / 喜马拉雅等听书结果按「书 → 章节」两级打开
- 喜马拉雅等歌曲搜索为空时，自动回退专辑搜索

### 介绍文案

- 应用中心 / README / 关于页简介补充落雪、澜音、MusicFree、BakaMusic 音源支持说明

## 安装 / 更新

- x86：`lemon-music-1.2.17.17-x86.fpk`
- ARM：`lemon-music-1.2.17.17-arm.fpk`
